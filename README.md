# keypad-basedproduct-counting-and-automatic-batch-packing-system-with-station-sensing-using-lpc2129

Keypad-Based Product Counting and Automatic Batch Packing System using ARM7 LPC2129

Project Overview

This project is designed to automate product counting and batch packing using the ARM7 LPC2129 microcontroller. The system uses a keypad to enter the required quantity and IR sensors to detect and count products. A conveyor belt moves the products automatically, while an LCD displays the product count and system status.

Components Used

- ARM7 LPC2129 Microcontroller
- IR Sensors
- 4×4 Matrix Keypad
- 16×2 LCD Display
- DC Motor
- Motor Driver
- Red and Green LEDs
- Buzzer

Technologies Used

- Embedded C
- Keil µVision
- Proteus Design Suite

Working Principle

1. Enter the required product quantity using the keypad.
2. Press the START key to start the conveyor belt.
3. IR sensors detect and monitor product movement.
4. The microcontroller counts the products and displays the count on the LCD.
5. Once the target quantity is reached, the conveyor stops automatically.
6. The LED and buzzer indicate batch completion.

Applications

- Manufacturing Industries
- Packaging Industries
- Food Processing Industries
